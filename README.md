# PUBG Intro Manager

This small program will help you load into PUBG a bit faster by removing intro movies.

## Features

- **Automatic Directory Detection**
	- Scans Windows Registry & parses Steam library manifests to find the game.
- **Safe Toggle System**
	- Appends `.bak` to movie files instead of deleting them. Useful for restoring them later.
- **No Dependencies**
	- You don't need to install anything more. Simply run the executable.
- **Anti-Cheat compliant**
	- Toggling movies on & off does not trigger the anti-cheat (bold to assume it works in the first place).

## Usage

1. Download the latest version from the [**Releases**](https://github.com/catsflex/pubg-intro-manager/releases) tab.
2. Run the executable as an **Administrator**.
3. Select an option from the menu.
